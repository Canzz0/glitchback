Bugloop widget demosu

Sağ alttaki Sorun bildir butonuna basın. Aşağıdaki iki buton bilerek hata üretir; önce onlara basıp sonra bildirim açarsanız, konsol hatasının ve başarısız isteğin bildirime otomatik eklendiğini görürsünüz.

Önce rapor sunucusunu açın: BUGLOOP_ALLOWED_ORIGINS=http://localhost:3000 npm run serve, sonra bu klasörü npx serve examples/demo ile yayınlayın. GitHub token'ı yoksa raporlar sunucunun terminaline yazılır.
